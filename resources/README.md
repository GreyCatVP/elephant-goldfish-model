# Shared resources

These files are loaded by EGM skills and reviewers. For installation and usage,
see the [documentation](../docs/README.md).

## Document standards

Choose a standard based on the artifact being written or reviewed.

| Standard | Use it to assess |
| --- | --- |
| [Feature specification](document_standards/feature-spec-standard.md) | A feature's problem, scope, alternatives, and risks. |
| [Heilmeier catechism](document_standards/heilmeier-standard.md) | A project proposal's objectives, value, risks, and success criteria. |
| [Implementation readiness](document_standards/implementation-readiness-standard.md) | Whether an implementation plan resolves design decisions and defines testable steps. |
| [Re-implementation](document_standards/re-implementation-standard.md) | Whether documentation describes existing behavior precisely enough to reproduce it. |
| [Zoom out](document_standards/zoom-out-standard.md) | Whether a proposal addresses the root problem at an appropriate level of detail. |

## Drafting instructions

[Execution instructions](execution_instructions.md) define the drafting skill's
interaction rules and restrictions on implementation work.

These paths are referenced by skills and agents. Update their references and
run the repository's link checks when moving or renaming a resource.
